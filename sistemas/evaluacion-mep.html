Información del Sistema de Evaluación MEP

Tipos de Evaluación

  • ✓ Formativa: Materno/Transición
  • ✓ Sumativa: 1° a 9° año
  • ✓ Continua: Durante todo el proceso

Porcentajes Oficiales

  • I Ciclo: 65% TC + 10% TA + 15% PE + 10% AS
  • II Ciclo: 60% TC + 10% TA + 20% PE + 10% AS
  • III Ciclo: 50% TC + 10% TA + 30% PT + 10% AS

Escala de Calificación

  • I-II Ciclo: Aprobado (70-100) / Reprobado (0-69)
  • III Ciclo: Excelente (90-100) / Bueno (80-89)
  • III Ciclo: Aprobado (70-79) / Reprobado (0-69)

Instrucciones Rápidas

  1. 1. Seleccione el ciclo educativo correspondiente
  2. 2. Ingrese la lista de estudiantes del grupo
  3. 3. Registre las calificaciones por componente
  4. 4. El sistema calculará automáticamente la nota final
  5. 5. Genere reportes y boletines en formatos oficiales
